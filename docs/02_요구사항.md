# 📌 NoteFlow 요구사항 정의서 (V1)

## 1. 프로젝트 개요

### 프로젝트명
NoteFlow

### 프로젝트 목표

메모와 Todo를 쉽고 직관적으로 관리할 수 있는 모바일 우선(Mobile First) 생산성 웹 애플리케이션(PWA)을 개발한다.

React와 TypeScript를 기반으로 개발하며, 추후 Firebase를 연동하여 실제 서비스 수준의 CRUD 기능을 구현한다.

---

## 2. 개발 환경

|구분|기술|
|---|---|
|Frontend|React + TypeScript + Vite|
|Style|Tailwind CSS|
|Routing|React Router|
|Database|Firebase Firestore (예정)|
|Hosting|Firebase Hosting 또는 Vercel|
|Version Control|Git / GitHub|

---

# 3. 화면 구성

|화면|설명|
|---|---|
|Home|오늘 날짜, 오늘 Todo, 최근 메모를 보여주는 대시보드|
|Memo|메모 목록 조회 및 검색|
|Note Editor|메모 작성 및 수정|
|Todo|Todo 목록 조회|
|Todo Editor|Todo 작성 및 수정|
|Calendar|날짜별 메모 및 Todo 조회|
|Settings|앱 설정|
|FAB Menu|새 메모 / 새 Todo 선택|
