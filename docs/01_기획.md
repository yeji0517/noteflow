# NoteFlow 프로젝트 기획서

## 1. 프로젝트 개요

### 프로젝트명
NoteFlow

### 프로젝트 소개
NoteFlow는 메모(Notes)와 할 일(Todo)을 하나의 서비스에서 관리할 수 있는 생산성(Productivity) 애플리케이션이다.

사용자는 메모를 작성하고 관리할 수 있으며, Todo를 통해 일정을 효율적으로 관리할 수 있다. 또한 AI 맞춤법 검사 기능을 제공하여 메모 작성의 편의성을 높이고, 모바일 환경을 고려한 UI를 통해 실제 서비스 수준의 사용성을 목표로 한다.

본 프로젝트는 React와 Spring Boot를 활용한 Full Stack 프로젝트이며, 웹으로 개발한 후 추후 Capacitor를 이용하여 Android 앱으로 변환하고 Google Play Store 배포를 목표로 한다.

- 기능 단위로 Git Commit 및 Push를 진행한다.
- UI를 먼저 구현한 후 API를 연결한다.
- 컴포넌트 재사용성을 고려하여 개발한다.
- 기능 구현 후 반드시 테스트를 진행한다.
- 발생한 문제는 docs/06_트러블슈팅.md에 기록한다.
- 모든 주요 기능은 GitHub Issue 및 문서와 함께 관리한다.
